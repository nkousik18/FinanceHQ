About This Project

The Problem

Loan documents are dense, jargon-heavy, and time-consuming to review. Analysts manually extract rates, tenure, repayment schedules, and applicant data — a slow, error-prone process.

The Solution

A retrieval-augmented pipeline that extracts, chunks, and indexes PDF text via FAISS, then routes natural-language queries through intent classification + A/B-tested prompt variants to a hosted LLM.

MLOps Angle

Every production query is logged to MLflow. An epsilon-greedy selector (ε = 0.1) evaluates v1 vs v2 prompt variants per intent and routes to the lower-latency winner once ≥ 10 runs are collected.

Engineering Scope

Full-stack: FastAPI service, Django UI, Docker Compose, 115+ tests, 6 REST endpoints, multi-document sessions with merged FAISS indexes, and real SSE streaming responses.
