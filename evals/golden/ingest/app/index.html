Page Labeller

pick a page 100%

Goal: make the labels match the page exactly. You're building the answer key.

Boxes: click a box to select it. Drag to move, drag a corner to resize. D (or "Draw box") then drag on the page to add a box. Boxes only need to be roughly right.

Type: number keys set the selected box's type:
1 text 2 section_header 3 title 4 list 5 table 6 page_header 7 page_footer 8 page_number 9 other

Other keys: Delete remove box · arrows nudge (Shift = 5pt) · Esc deselect · Ctrl/Cmd+Z undo · Ctrl/Cmd+S save.

Tables: set a box's type to table, then open the Table tab. Fix rows/columns and cell text (numbers exactly). Merged cell: select it, set its row/column span. Big table: paste its rows into "Fill from pasted text".

Form fields (CFPB pages): add every label → value pair, e.g. Loan Amount → $162,000.

Order: the order a person reads the boxes. "Auto order" sorts top-to-bottom; fix columns by hand.

Done? Problems at the bottom must be empty, then "Mark verified".

From-scratch pages start empty on purpose: label them without looking at Docling's output.
